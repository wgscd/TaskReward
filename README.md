# 「成长星・任务积分奖励系统」项目总结

## 项目定位

面向青少年家庭的**任务积分激励桌面应用**：家长设置任务，孩子完成后获得积分，用积分兑换奖励，并通过历史积分解锁成就 —— 形成 "努力 → 积分 → 奖励" 的正向循环。UI 采用深紫渐变侧栏 + 浅色卡片式内容区的高端现代风格。

## 技术栈

- **WPF（.NET Framework 4.8）**，纯 MVVM 架构（`ViewModelBase` + `RelayCommand`）
- 数据用 **JSON** 持久化（框架内置 `DataContractJsonSerializer`，无需第三方包）
- 无边框自绘窗口 + 统一主题资源字典（`Theme.xaml` 集中管理配色 / 按钮 / 卡片 / 滚动条等样式）

## 功能模块（左侧 5 个页面）

**1. 首页概览**

- 大卡片展示当前可用积分、历史累计积分、当前称号
- 下一成就进度条、"还差多少分" 提示
- 快捷统计卡：今日已完成 / 我的任务 / 商城好物 / 成就进度
- 成长小贴士使用指引

**2. 我的任务**

- 任务项增 / 删 / 改 / 完成打勾，含名称、文字描述、Emoji 图标、奖励积分
- 完成打勾即加积分（取消自动扣回），总积分实时统计
- **任务模板库**：预置 10 个常用模板，一键添加到任务，模板可单独增删改
- 空状态提示、模板来源徽标

**3. 每日任务**

- 日期导航（前一天 / 后一天 / 回到今天），每天可添加**多个单日任务项**
- 每项独立完成打勾、编辑、删除，实时显示当日完成进度

**4. 积分商城**

- 预置 8 件奖励商品（名称 / 描述 / 图标 / 兑换积分 / 库存）
- 积分不足或库存为 0 自动拦截，兑换确认后扣减积分
- 商品可增删改；兑换记录 + 历史累计消费展示

**5. 我的成就**

- 按**历史累计积分**自动解锁 9 级成就（初出茅庐 → 传奇之星）
- 徽章等级配色（铜 / 银 / 金 / 钻 / 传说）、已解锁 / 未解锁状态、每枚进度条
- 总解锁进度展示

## 数据与健壮性

- 数据自动保存到程序同目录 `data.json`；删除该文件即重置系统
- 首次运行自动生成预置模板、商品、成就定义
- 数据损坏时自动备份为 `.bak` 并重建；全局异常有友好提示
